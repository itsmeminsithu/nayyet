## Reproduce

From the repository root:

```bash
python3 tools/build_calendar.py
cd web
npm test
```

Android:

```bash
cd android_flutter
python3 prepare_android.py
flutter test
flutter run
```

macOS Swift core:

```bash
cd ios_swift
swift test
xcodebuild -project NayYet.xcodeproj -scheme NayYet -sdk iphonesimulator -configuration Debug CODE_SIGNING_ALLOWED=NO build
```

The hand-picked JSON fixtures are generated by the calendar implementation; they are regression fixtures, not independent proof. The separate full-range reference comparison above supplied independent verification at packaging time.
